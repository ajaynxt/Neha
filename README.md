# AJAY NXT Portfolio

GitHub Pages-ready cinematic portfolio for **Ajay Saini / AJAY NXT**.

## What is included

- All **7 supplied cinematic scroll clips** are used in the page.
  - 1 clip drives the hero.
  - 6 clips are paired into 3 full-screen scroll chapters with crossfades.
- Featured client work: Diamond Restaurants.
- Filterable **25 demo website** library.
- Video Editing section remains included with the **4 supplied playable films**.
- Play / pause / seek / volume controls through the video modal.
- About, capabilities, contact and social links.
- Responsive desktop + mobile behavior.
- Reduced-motion fallback.
- Plain HTML/CSS/JS, so there is **no build command**.

## Folder structure

- `index.html`
- `assets/css/styles.css`
- `assets/js/script.js`
- `assets/images/` — favicon + video poster frames
- `assets/videos/` — 7 scroll clips + 4 video-editing films
- `.nojekyll`

## GitHub Pages

1. Upload the contents of this ZIP to the repository root.
2. GitHub → **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save.

Every individual file is well below GitHub's browser upload limit. The complete ZIP is also kept below 25 MB.
